如何判断计划内重置与突然重置

计划时间变化本身不等于额度重置。缺少重置时间、采样跨越多个周期或处于时间边界时，标记为待确认。服务不会因倒计时结束自动把额度改成 100%。卡片中的“上次重置”不受观察范围筛选影响；检测时间是首次采样发现变化的时间，突发重置只能定位到两次采样之间。

本服务只能看到上传的数据，不能确定变化是否由平台赠送、人工兑换或额度校正引起。旧采样会保存，但不会回改已经生成的判断。
