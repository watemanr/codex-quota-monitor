每个 Codex 账号可以设置独立的 Bark 服务器和接收 key。只填写服务器地址，例如 http://你的服务器:40011；key 单独填写，保存后不会在网页回显。系统使用 Bark 的 POST /push 接口发送。

填 0 关闭定时报告；启用时最短 5 分钟。报告会注明最后采样时间。
